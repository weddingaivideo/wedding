## 二、欧美文化中已验证的未覆盖需求

### 🥇 Tier 1 — 高需求 + 纯前端可实现 + 强流量

#### 1. 婚礼筹备清单生成器（Wedding Checklist Generator）
- **需求量：约 40,000 次/月**（本niche中最大的工具关键词，OurVows 公开数据）
- **文化背景**：美国婚礼平均筹备 12–16 个月、约 200+ 个任务节点（订场地、订摄影师、试菜、发邀请、领证时间窗），任务清单是这个市场的基础设施。
- **验证**：The Knot、Zola、OurVows 等头部平台全部内置此工具；说明它是流量入口级功能。
- **实现**：按婚礼日期倒推的任务生成 + localStorage 勾选进度条。零后端。
- **注意**：竞争激烈，需差异化（按倒计时周数动态生成、可打印 PDF）。

#### 2. 婚礼酒水计算器（Wedding Alcohol Calculator）
- **需求量：约 6,000 次/月**
- **文化背景**：美国相当比例的新人 BYOB 自购酒水（省钱 + venue 允许外带），"每位成人每小时 1 杯"是行业通则。规则完全可公式化：宾客数 × 时长 × 饮酒比例 ÷ 啤酒/红酒/烈酒占比 → 瓶数/箱数。
- **验证**：WedBuild、calculator.city 系列等多个独立免费工具在竞争此关键词；均有完整页面级 SEO 内容。
- **实现**：纯计算 + 可复制购物清单。最理想的低成本工具。

#### 3. 婚礼誓言撰写助手（Wedding Vow Writer / Builder）
- **需求量：vow writer 6,000 次/月；"wedding vows" 5,000；"wedding vows examples" 2,000**（grindsuccess 词表）
- **文化背景（关键统计）**：The Knot 2026 Real Weddings Study（10,474 对新人）：**61% 的新人自己写誓言，历史最高**（2019 年仅 44%）。非宗教/世俗婚礼占比上升，誓言承担了更多情感重量。150–250 词、四段结构（开场/故事/承诺/收尾）。
- **验证**：OurVows、myweddingkit、pix.wedding 均已做免费版本。
- **实现**：**无需 AI**——四段式模板 + 填空 + 语调切换 + 字数/朗读时长计时器（150 wpm 换算）。与主产品（视频）天然协同：誓言是婚礼视频的核心素材。

#### 4. 婚礼致辞撰写工具（Best Man Speech Writer）
- **需求量：speech writer 8,000 次/月；"wedding speeches" 4,500**
- **文化背景**：伴郎致辞是欧美婚礼的固定环节（父方致辞→新郎→伴郎压轴，5–8 分钟），"写不出"是普遍痛点——thebestmanspeech.com 整个站点就靠这个活着。
- **实现**：角色选择（伴郎/伴娘/父亲/母亲）× 结构模板（开场→2–3 个故事→夸新人→举杯）× 幽默/深情风格。纯前端模板组合。

#### 5. 宾客到场率计算器（Guest Count Calculator）
- **需求量：约 8,000 次/月**
- **文化背景**：美国 RSVP 文化成熟，但邀 200 人实际到场约 65–80%（本地/异地/目的地婚礼衰减率不同）——直接决定餐位、蛋糕、酒水、椅子租赁数量。
- **实现**：输入邀请数 + 婚礼类型/距离 → 预测到场数。纯公式。

### 🥈 Tier 2 — 需求真实，视资源排期

#### 6. 婚礼当天流程时间线生成器（Wedding Day Timeline Generator）
- **需求量：约 5,000 次/月**
- **文化背景**：欧美婚礼有固定的"仪式流程锚点"（first look → ceremony → cocktail hour → grand entrance → first dance → toasts → cake cutting → bouquet toss → send-off），且需发给摄影师/DJ/场地协调员。
- **验证**：bespoke-bride 的生成器证明可完全浏览器端实现（从仪式时间倒推全天安排 + .ics 日历导出）；weddingtimeline.org、eventrundown.com 均在竞争。
- **复杂度较高**：需要拖拽/编辑 UI + PDF 导出。

#### 7. 婚礼礼物金额计算器（Wedding Gift Calculator）— **客群视角工具**
- **需求量**：The Knot 宾客研究：宾客平均送 **$150**，按关系亲疏 $50–$300+。多个独立计算器在竞争（toolaspect、moneydeck、calculator.city）。
- **战略价值**：这是唯一直接服务**宾客**（而非新人）的工具——受众比新人群体大 10 倍以上，可带来站外新流量。美国"cover your plate"礼仪传统 + 现金礼文化（不适配欧洲部分市场，注意区域）。
- **实现**：关系 × 是否携伴 × 目的地婚礼 × 预算 → 建议区间。纯公式。

#### 8. 婚后改名清单（Name Change Checklist）— 美国特有
- **文化背景**：美国新娘婚后改姓是主流，流程有严格顺序：结婚证认证副本 → **Social Security（必须第一步）** → DMV 驾照 → 护照 → 银行 → 雇主/工资 → 选民登记。顺序错了会被退回。
- **验证**：namechange.com 靠卖付费改名 kit 盈利、legalhelp.us 做内容站——存在真实商业需求。
- **实现**：带顺序的互动清单 + 每州差异说明（内容量大，可先做联邦通用版）。纯前端 + localStorage。
- **区域警告**：仅美国有效；欧洲（法/德/西）婚后改名流程完全不同甚至不常见。

#### 9. 感谢卡文案生成器（Thank-You Note Generator）
- **文化背景**：婚礼后 4–6 周内需给每位送礼宾客手写感谢卡（100–150 张），现金礼不可提金额是铁礼仪。
- **验证**：Zola（免费）、theweddingplanner.ai、text-my-wedding（纯浏览器端批量生成）均已入场。
- **实现**：礼物类型（实物/现金/集体礼/仅到场）× 语气 → 文案。text-my-wedding 的"整张礼单批量生成"是值得借鉴的差异化。
- **战略价值**：婚后触点，可引导用户回到 gallery / 视频。

#### 10. 婚礼蛋糕份量计算器（Wedding Cake Servings Calculator）
- **文化背景**：蛋糕按 1"×2" 标准切法计算份数，"100 人需要几层几寸"是高频问题；英国用 finger portion、美国用 dessert portion，可双区域适配。
- **验证**：plana.wedding、weddingcakeshub、wedcalc.co.uk（英版）均有专门工具。
- **实现**：查表 + 组合推荐。纯前端，工作量最小。

### 🥉 Tier 3 — 有需求但不优先

- **着装代码解读器（Dress Code Decoder）**：被多个来源称为"被 Google 最多的婚礼话题之一"（Vogue 有专文），但内容型 > 工具型，更适合做成 blog 文章而非 tool。
- **服务商小费计算器（Vendor Tipping Calculator）**：约 4,000 次/月，纯美国文化（小费），欧洲无效——与目标"欧美"整体冲突，仅美国市场值得。
- **婚礼倒数计时器（Wedding Countdown）**：5,000 次/月，但已有大量通用倒计时工具（countz.io 等），且与本站已有"电子邀请视频"功能重叠，差异化弱。
- **供应商提问清单（Vendor Questions Generator）**：4,000 次/月，内容量大、同质化严重。

## 三、需求验证方法说明

Google Trends 网页端直接抓取被限流（Error 429）且其数据依赖 JS 渲染无法静态获取，故采用四路间接验证：

1. **公开搜索量数据**：OurVows（竞品工具站）在工具页公开标注各关键词月搜索量（checklist 40k、hashtag 15k、budget 12k 等）；grindsuccess 发布的 243 个婚礼行业关键词词表。
2. **竞品密度**：每个候选关键词均有 3–5 个独立免费工具站在竞争（工具站不会为零流量关键词建页面 + 写完整 SEO 落地页，页面存在本身即需求证明）。
3. **权威文化统计**：The Knot Real Weddings Study（61% 新人自写誓言）、The Knot 宾客研究（平均 $150 礼金）——这些数字被竞品页面反复引用。
4. **行业媒体覆盖**：Vogue（着装代码）、Zola（感谢卡）、官方政府页（改名流程）均有专题内容。

## 四、优先级建议（综合需求 × 可实现性 × 与主产品协同）

| 优先级 | 工具 | 月搜索量 | 前端成本 | 与 AI 视频协同 |
|---|---|---|---|---|
| P0 | 酒水计算器 | ~6k | 极低 | 弱 |
| P0 | 蛋糕份量计算器 | ~2k | 极低 | 弱 |
| P0 | 誓言撰写助手 | ~13k(合计) | 低 | **强（誓言=视频素材）** |
| P1 | 致辞撰写工具 | ~12k(合计) | 低 | 强 |
| P1 | 宾客到场率计算器 | ~8k | 极低 | 中（预测值可联动相册/座位表） |
| P1 | 备婚清单生成器 | ~40k | 中 | 中 |
| P2 | 礼物金额计算器 | ~4k | 极低 | 弱（但打开"宾客"新客群） |
| P2 | 感谢卡生成器 | ~3k | 低 | 中（婚后回访触点） |
| P2 | 当天时间线生成器 | ~5k | 高 | 中 |
| P3 | 婚后改名清单 | ~5k | 中(内容) | 弱（美国限） |

**核心判断**：
- 若目标是**流量最大化** → 先做备婚清单（40k/mo 是全站最大的工具词）；
- 若目标是**转化主产品** → 先做誓言/致辞工具（文本产出物直接成为 AI 婚礼视频的脚本素材，形成"写完誓言→生成视频"闭环，这是竞品没有的叙事）；
- 若目标是**最低成本快速上线** → 酒水/蛋糕计算器，一天可交付。
