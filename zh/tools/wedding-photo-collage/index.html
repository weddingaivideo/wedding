什么时候用婚纱照拼图

拼图是婚礼产出中极其实用的视觉资产，一张精心设计的版式可以同时用作请柬、答谢卡内页、相册封面、父母礼物和 Instagram 总结帖。诀窍在于选择匹配媒介的版式 —— Instagram 忌把脸放边缘、冲印忌边缘白边不均匀、父母相册则需要留足呼吸空间让照片之间不显拥挤。

请柬（纸质或电子）

  1. 2 × 2 方形（1:1）。紧凑，印在 5×5 卡片上非常清爽，四宫格可充当中央详情文字周围的"画框"。
  2. 横版条幅（16:9）。以一张全景订婚照为主视觉，再用三张细节照（戒指、花艺、场地）环绕。
  3. 竖版条幅（4:5）。杂志风的加长版请柬，在 Instagram DM 里滚动顺畅，加上细边也能以 5×7 印刷。

答谢卡（以及给父母的礼物印刷）

  1. 2 × 3（4:5）。6 张是答谢卡的"魔法数字" —— 内容够丰富又不显拥挤。竖版比例适配美规 4×6 和 5×7 卡片。
  2. 3 × 3（1:1）。经典的九宫格，永不过时。印 5×5 或发 Instagram 都好看。
  3. 3 × 4（4:5）。给父母相册内页用 —— 把当天最重要的 12 张照片放一张里。可以配合我们的 为婚纱照加文字工具给每个格子加注。

社交媒体总结（Instagram、Facebook、微信）

  1. 3 × 3（1:1）。朋友圈友好的九宫格。Feed 里是方的、轮播每一页也是方的。
  2. 2 × 3（4:5）。Instagram 竖版六宫格 —— 在算法预览里比方形多占 60% 的纵向空间，更能"挡人滑动"。
  3. 横版条幅（16:9）。用于 Facebook 封面、LinkedIn 或婚礼博客顶部图。宽屏比例适合 Instagram 网格里的横版裁切。

为什么我们做成了浏览器内工具

绝大多数在线拼图工具会把你的照片上传到服务器，处理完再发回来。大部分场景问题不大，但婚纱照有特殊的隐私性 —— 经常包含只给家人看的瞬间、幕后的抓拍、以及未经本人同意上传到远程的宾客照。我们把这款工具设计成 从不上传服务器：Canvas API 在你的浏览器标签页里完成合成，PNG 文件直接落到你的设备。不分析你的照片、不收集训练数据、不需要账号。

同样的思路也让我们不必担心字体托管问题。大部分在线工具需要把字体打包到页面里才能在渲染时套用 —— 这常常被 CDN 屏蔽、强力广告拦截、字体许可限制等情况卡住。我们用 Google Fonts 的 font-display: swap 策略：Canvas 在画字幕之前给字体一个短暂加载时间，加载完成后再渲染。最终拼图里不会出现"豆腐字"或意外的回退字体。

无障碍 & 这款工具 不是做什么的

拼图是一种视觉产物。带字幕的版本自带一行文字，渲染时叠在背景色之上并加柔和阴影，保证在浅色或深色图片上仍清晰可读。如果你需要在每张格子里放一长段文字，请先用我们的 "加文字" 工具给每张照片单独加文字，然后再带标签放进拼图。我们刻意不做"纯文字拼图" —— 屏幕阅读器无法从 JPG 里读出故事，而烧字幕的图像会把视障朋友挡在你的婚礼叙事之外。需要文字版叙事请用原始相册 + 配文卡片。

分步教程

  1. 先选好照片。打开你最爱的相册文件夹，挑 4、6、9 或 12 张。按你希望出现的顺序大致排好 —— 左到右、上到下。
  2. 拖入照片。拖到拖放区，或者点击从文件夹选择。预览缩略图立刻出现，方便你确认方向是否对。
  3. 选择一种排版。点击六张排版缩略图中的任意一个。下方"最适合"提示会变 —— 把它当作自检。
  4. 选择比例。1:1 用于 Instagram，4:5 用于竖版 Instagram 与多数冲印，16:9 用于桌面横幅，4:3 用于传统 6×4 冲印。
  5. 调整间距、背景与字幕。拖动间距滑块；选一个与主图色调形成对比的背景色；输入一行字幕并选定字体。
  6. 生成拼图。点 生成拼图。Canvas API 用"裁剪填充"语义合成每张照片 —— 脸不会被拉变形、横版照片也不会出现尴尬的"长边放大"。
  7. 下载。下载 PNG 按钮在生成后一直可用，方便你用不同设置重新生成再导出。

常见问题

一张拼图最多能放几张照片？

2 到 12 张。每个版式对应的固定张数：2 × 2 = 4，2 × 3 = 6，3 × 3 = 9，3 × 4 = 12，横版条幅 = 5，竖版条幅 = 5。如果放入数量少于版式要求，剩余格子会渲染成背景色；多于版式要求时只用前 n 张（被剔除的会在文件列表里标注）。

照片会被拉伸变形吗？

不会。每张照片都按 object-fit: cover 的方式绘制 —— 居中缩放以填满格子，超出部分对称裁剪。即使在同一张拼图里混用竖版和横版照，人脸和身体都能保持构图。

输出是什么格式？

单个 PNG，按印刷分辨率输出。画布尺寸与你选的比例一致 —— 比如 1:1 出 1500 × 1500 px，4:5 出 1500 × 1875 px，16:9 出 1920 × 1080 px，4:3 出 1600 × 1200 px。PNG 是无损的，所以文件比 JPG 大，但画质和你预览时看到的完全一致。

iPhone 或 Android 上能用吗？

可以。iOS Safari 和现代 Android Chrome 都支持 Canvas API 和 Google Fonts。手机上点击拖放区会打开相册选择。

为什么字幕只有一行？能不能加多行？

单行字幕在拼图缩小（Instagram 缩略图、电子卡预览、5×5 印刷件）时仍然清晰易读。需要更长字幕或每格标签，请先用 为婚纱照加文字 工具给每张原照单独加文字。

我的照片会被上传吗？

不会。每个像素都由你浏览器的 Canvas API 在本地合成。没有服务器。放下照片后你甚至可以断掉 Wi-Fi，工具依然可用。
