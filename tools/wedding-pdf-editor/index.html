What this wedding PDF editor actually does

A wedding produces paperwork in pieces: the photographer's contract, the venue's floor plan, the seating chart, the caterer's guest count, the invitation draft, the timeline the planner keeps on her phone. Then everyone asks for one PDF. This tool puts those pages into one file, in the order you want, without sending a single byte to a server.

It does five jobs, and it does all five on the same page:

  • Merge several PDF files into one document, in any order you choose.
  • Split a document into separate PDFs by page groups such as 1-3, 4, 5-, delivered as one ZIP archive.
  • Reorder pages by dragging them, and untick the ones you do not want in the file.
  • Rotate any page by 90, 180 or 270 degrees, which is the fix for the scan that came in sideways.
  • Unlock a file that opens but blocks printing or editing, and save a copy without the restrictions.

Everything runs inside your browser. There is no account, no upload, no watermark, and no limit on how many files you process over time.

How to merge PDF files

  1. Drop the PDF files into the box, or click the box to browse for them. The tool reads the page count and the real size of every page.
  2. Check the order in the page list. The files arrive in the order you picked them, so every page of the first file comes before every page of the second one.
  3. Drag any page up or down until the list reads the way you want it.
  4. Press Merge into one PDF. The file is written in your browser and saved straight to your device.

Merging copies the page content as it is. A scan is not recompressed, a vector drawing is not turned into a picture, and every page keeps its own size, so a document with A4 pages and Letter pages stays mixed.

How to split a PDF into separate files

Type the page groups into the Page groups for the split box. A group is a page number, a range such as 4-8, or an open range such as 5- for everything from page 5 to the end. Separate the groups with commas: 1-3, 4, 5- gives you three files.

The page numbers count the pages of the merged order, so untick the pages you do not want first and the numbers will match what you see. Every group becomes its own PDF and all of them arrive in one ZIP archive, because browsers block a page that tries to save five separate files at once.

How to reorder and rotate PDF pages

Drag a page by its handle on the left, or use the up and down arrows. The arrow buttons do the same thing as the drag and they work on a phone, where dragging is awkward. Untick a page and it stays out of the merged file.

The rotate buttons turn a page 90 degrees each time, so two presses give you 180 and three give you back to 360. The rotation is applied to the exported copy; the file on your device is never changed. Each row also shows the file name and the page number the page came from, which is what you need when you are looking for one page in a long list.

Two types of PDF password, and which one you have

Almost every question about locked PDFs mixes two different things together. Knowing which one you are holding saves a lot of time.

  • Type 1: the file needs a password to open. The password is the key to the whole document. There is no way around it, and no tool, online or offline, can read the pages without it. If you have the password, type it into the box under that file and the pages join the list. The export then has no password, so you can send the merged file to your photographer without sending the key.
  • Type 2: the file opens, but printing, copying or editing is blocked. This is an owner password, and it does not stop you reading the file. The pages open normally here, and the Save a copy without a password button writes the same pages out as a new file with those restrictions gone.

There is a third limit worth naming. The encryption that can be opened in a browser is the older standard kind: RC4 and AES-128, up to PDF 1.6. Many newer PDFs use AES-256, which arrived with PDF 2.0, and those files cannot be opened here at all. The tool says exactly that instead of failing quietly, because a silent failure would leave you thinking the file was empty.

Common wedding use cases

  • One file for the venue. The ceremony plan, the floor plan, the seating chart, the run sheet and the caterer's counts, in that order, in one PDF the venue can print once.
  • Contracts for the planner. The photographer, the caterer, the florist and the rental company in one document, with the pages rotated so every contract is upright.
  • The print packet. The invitation draft, the RSVP card, the menu and the timeline, ready to hand to the printer as one file.
  • Scans from the phone. The phone's note app or scanner makes a PDF with one page per photo, often sideways. Merge them, rotate the strays and the file is ready to print.
  • The gift and thank-you list. A long checklist split into a few pages so the list can be printed in sections and handed to two people.

Frequently asked questions

Are my files uploaded? Does my file never leave my device?

No. Your PDFs are opened, rearranged and written by a small program that runs inside your own browser, so the file never leaves your device. Nothing is sent to a server, there is no account, and no watermark is added.

Is there a limit to how many PDFs I can merge at once?

Yes. One run takes up to 20 files of up to 200 MB each, and up to 1,500 pages in the merged document, and the real ceiling is the memory of your own device: a browser tab that runs out of memory stops the job. A few hundred pages is comfortable, and more than that is better done in two runs.

In what order will my merged PDF files appear?

In the order you see in the page list. The files are added in the order you picked them, so every page of the first file comes before every page of the second file. You can drag any page up or down, so the order in the exported PDF is always the order on screen.

Can I delete and reorder pages after I merge files?

Yes, and you do it before the export rather than after it. Drag a page to move it, use the arrow buttons, or untick it to leave it out of the PDF completely. Each row shows the file name and the page number it came from, so you can find the page you want in a long list.

Will the formatting of my merged documents be preserved?

The page content and the page size are kept exactly as they were: nothing is resized, nothing is cropped, and vector text stays vector text, so the merged file prints as sharply as the originals. What is not rebuilt is the extra structure around the page, such as bookmarks, form fields and interactive buttons, because the tool copies page content instead of editing the original document.

Does merging PDFs reduce the quality of my files?

No. Merging copies the page content as it is, so a scan is not recompressed and a vector drawing is not turned into a picture. The only thing that changes is the size of the result, because the pages of every file are stored in one document.

Can I merge password-protected PDFs?

Yes, as long as you know the password. When a file cannot be opened, the tool shows a password box under that file; type the password and the pages join the list. A PDF that needs a password to open cannot be read by any tool without that password, including this one.

Can I unlock a PDF without the password?

It depends on which kind of lock the file has. A PDF that opens normally but blocks printing, copying or editing can be saved here as a new file with those restrictions removed, and no password is needed for that. A PDF that needs a password to open cannot be unlocked without it, and this tool does not guess passwords. The encryption that can be opened is the older standard kind, RC4 and AES-128, up to PDF 1.6. Many newer PDFs use AES-256 (PDF 2.0), and those cannot be opened here; the tool says so instead of failing quietly.

What page sizes and resolutions does the editor support?

Every page size there is. The tool reads the real size of each page, such as Letter, A4, Legal, A5 or Tabloid, and the exported page keeps it, so a document with A4 pages and Letter pages stays mixed. There is no resolution to choose, because a PDF page is not a photograph and vector text stays sharp at any size. The tool works on PDF files only, so a photo in HEIC or AVIF has to be turned into a PDF first.

How is this different from an image tiler, and what format does the export come in?

An image tiler lays separate photos out on a new page, like a contact sheet. This tool never draws anything and never changes a picture: it takes the pages that are already in a PDF and puts them in the order you want. The export is a PDF. A merge gives one file, and a split gives a ZIP archive with one PDF per group.
