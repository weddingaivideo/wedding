## 成長記録動画とは何か

### 基本的な concept

成長記録動画は、カップルそれぞれの幼少期から現在までの photo や video を chronological に並べ、一本の動画として仕上げるものです。単なる photo の slideshow ではなく、二人の人生の journey を storytelling として表現する art です。

### なぜ人気があるのか

1. **personal な connection**：ゲストが二人をより深く知ることができる
2. **感動的な storytelling**：幼少期から大人になるまでの変化が感動を生む
3. ** unique な content**：他の Wedding にはない original な動画
4. **家族との共有**：家族の history を Wedding の day に反映できる
5. **SNSで話題に**： unique な content は social media で拡散されやすい

## テンプレートの種類

### テンプレート1：タイムライン型

二人の人生を time line に沿って描く、最も standard なテンプレートです。

**構成：**
1. 花嫁の幼少期（30秒）
2. 花婿の幼少期（30秒）
3. 花嫁の学生時代（30秒）
4. 花婿の学生時代（30秒）
5. 出会いの scene（60秒）
6. 交際中の memory（60秒）
7. プロポーズ（30秒）
8. Wedding の day への期待（30秒）

### テンプレート2：パラレル型

花嫁と花婿の成長を parallel に描くテンプレート。同じ時期に何をしていたかを対比させます。

**構成：**
1. 同じ year の photo を左右に並べる
2. 同じ event （入学、 graduation ）を対比
3. 出会いの scene で二人が交わる
4. 以降は二人 together の photo

### テンプレート3：テーマ型

特定のテーマに沿って photo を selection するテンプレート。

**テーマの例：**
- 「笑顔の history 」：笑顔の photo のみで構成
- 「 adventure の history 」：旅行や event の photo で構成
- 「 family の history 」：家族との photo を中心に構成

### テンプレート4：インタビュー型

各 photo にナレーションを加えるテンプレート。本人や家族の voice が加わることで、より personal な動画に。

## 制作の step-by-step guide

### Step 1：素材の collection

**必要な素材：**
- 各 era の代表的な photo （各 era 3〜5枚）
- 可能であれば old い video も
- 出会い以降の couple photo
- プロポーズの photo または video

**素材 collection の tips：**
- 両親に old い photo を request
- smartphone の photo ライブラリを search
- social media の archive を活用
- photo album を scan する

### Step 2：ストーリーの planning

**物語の骨格を作る：**
1. 二人の origin story
2. 成長の turning point
3. 出会いの fate
4. love の deepening
5. future への展望

** script の draft：**
各 photo にどのような narration をつけるか、 script を draft します。短く、 emotion を伝える words を選ぶのが key です。

### Step 3：テンプレートの selection

[WeddingAI.video](/services/personalization/ai-video-generator/)では、 variety なテンプレートから選べます。

** selection の基準：**
- Wedding の theme に合ったデザイン
- photo の枚数に合った template
- 上映 time に合った length
- personal な preference

### Step 4：素材の配置と editing

**配置の rule：**
- chronological に並べる
- 各 photo の表示 time は3〜5秒
- 重要な photo は long く表示
- transition は smooth に

** editing の tips：**
- [スローモーション効果](/services/video-enhancement/slow-motion/)は emotion の scene だけに
- color correction で photo の color を統一
- [ヴィンテージ復元](/services/video-enhancement/vintage-restoration/)で old い photo を beautiful に

### Step 5：BGM とナレーションの追加

**BGM 選び：**
- 二人の theme song があれば最適
- なければ instrumental の ballad を選ぶ
- tempo の変化をつけて emotion を演出

**ナレーション：**
- 本人の voice で recorded するのが best
- 家族の voice を加えると more personal
- なければ text の narration でも OK

### Step 6：最終確認と output

**確認ポイント：**
- photo の順序は正しいか
- 長さは適切か（5〜7分が ideal ）
- BGM と narration の volume の balance
- text に error がないか
- 上映 environment に合った format か

## 素材 collection の detailed guide

### 両親からの old い photo の request

** request の仕方：**
- early に request （2〜3ヶ月前）
- scan して digital 化してもらうよう依頼
- caption 付きで情報をもらう（いつ、どこで、誰と）
- 可能であれば複数の photo を request

### digital 素材の整理

**整理の step：**
1. 全ての素材を一つの folder に collection
2. era 別に folder を分ける
3. 代表的な photo を selection
4. file 名を整理（例：「2000_幼少期_公園.jpg」）

### scan の tips

**scan 時の注意：**
- high resolution （300dpi以上）で scan
- 光の反射に注意
- 古い photo は丁寧に handling
- color 補正は later で行う

## 編集の advanced tips

### emotion を高める technique

** zoom と pan：**
- photo の一部を zoom して emotion を強調
- slow な pan で photo の全体を見せる
- 顔の表情を zoom で強調

** color の manipulation：**
- 重要な scene だけ color で、他は白黒に
- warm な color で family の scene を演出
- [ヴィンテージ復元](/services/video-enhancement/vintage-restoration/)で old い photo を modern に

**効果音の追加：**
- laughter の効果音
- applause の効果音
- nature の音（海、 forest ）

### テンポの管理

** rhythm を意識する：**
- music の beat に合わせて photo を切り替える
- emotion の高まりに合わせて tempo を変える
- 間を効果的に使う（沈黙も powerful ）

## 披露宴での上映方法

### 上映の timing

**最適な timing：**
- 両親の speech の後

- エンターテイメントの一部として

### 当日の preparation

**準備 list：**
- 会場の equipment を事前確認
- backup の media を用意
- volume の setting を事前にテスト
- 上映後の applause の timing を計画
