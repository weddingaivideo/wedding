## 一、恋爱时期素材

### 为什么需要这些素材？

婚礼视频不应该只记录婚礼当天。恋爱时期的素材能让你的视频更有**故事感**，让观众（尤其是不了解你们故事的宾客）更好地理解你们的爱情历程。

### 需要准备的素材

**照片类（建议10-20张）：**
- 第一次约会的照片
- 旅行中的合照
- 日常生活的甜蜜瞬间
- 特殊纪念日的照片（生日、情人节等）
- 求婚现场的照片（如果有的话）

**视频类（建议2-5段）：**
- 旅行中的视频片段
- 日常生活中的有趣视频
- 求婚现场的视频（强烈建议！）

**小贴士：** 如果恋爱时期的素材不多，不要担心。可以从社交媒体上翻找，或者问问朋友是否保存了你们的合照。即使只有几张照片，也比没有好。

## 二、备婚过程素材

### 为什么需要这些素材？

备婚过程是婚礼故事中很重要的一部分。试婚纱、选戒指、布置婚房……这些忙碌而甜蜜的瞬间，都是婚礼视频的好素材。

### 需要准备的素材

**照片类（建议15-30张）：**
- 试婚纱/礼服的照片
- 选戒指的照片
- 婚房布置的照片
- 婚礼请柬设计
- 喜糖/伴手礼准备
- 婚礼彩排的照片
- 和婚庆团队沟通的场景

**视频类（建议3-5段）：**
- 试婚纱的过程
- 婚房布置的过程
- 婚礼彩排片段

## 三、婚礼当天素材（最重要！）

婚礼当天是素材的核心来源。以下是按婚礼流程整理的详细清单：

### 1. 准备阶段

**新娘准备（建议20-40张照片 + 5-10段视频）：**

| 素材类型 | 具体内容 | 重要程度 |
|----------|----------|----------|
| 化妆过程 | 新娘化妆、做发型 | ⭐⭐⭐⭐⭐ |
| 穿婚纱 | 新娘穿婚纱的过程 | ⭐⭐⭐⭐⭐ |
| 婚鞋 | 婚鞋特写 | ⭐⭐⭐ |
| 婚戒 | 婚戒特写 | ⭐⭐⭐⭐⭐ |
| 新娘独照 | 穿好婚纱后的新娘单人照 | ⭐⭐⭐⭐⭐ |
| 与伴娘合照 | 新娘和伴娘们的合影 | ⭐⭐⭐⭐ |
| 与父母互动 | 父母帮新娘整理婚纱等 | ⭐⭐⭐⭐⭐ |
| 闺房氛围 | 新娘房间的环境和细节 | ⭐⭐⭐ |

**新郎准备（建议15-30张照片 + 3-5段视频）：**

| 素材类型 | 具体内容 | 重要程度 |
|----------|----------|----------|
| 穿西装 | 新郎穿西装的过程 | ⭐⭐⭐⭐ |
| 整理仪表 | 新郎整理领带、袖扣等 | ⭐⭐⭐ |
| 新郎独照 | 穿好西装后的新郎单人照 | ⭐⭐⭐⭐ |
| 与伴郎合照 | 新郎和伴郎们的合影 | ⭐⭐⭐⭐ |
| 与父母互动 | 父母帮新郎整理着装 | ⭐⭐⭐⭐⭐ |

### 2. 接亲环节

**建议素材量：30-50张照片 + 10-15段视频**

- 婚车车队
- 新郎到达新娘家
- 堵门游戏过程（这是最容易出搞笑素材的环节！）
- 新郎找婚鞋
- 新郎给新娘穿婚鞋
- 新郎抱/背新娘出门
- 上婚车的瞬间
- 婚车行驶中的画面

**重点提醒：** 接亲环节通常非常热闹，建议安排**至少两位摄影师**，一位跟拍新郎，一位跟拍新娘，确保两边的反应都能记录下来。

### 3. 婚礼仪式

**建议素材量：40-60张照片 + 15-20段视频**

这是婚礼视频中**最核心**的部分，每一个瞬间都很重要：

- 婚礼场地全景
- 宾客入场
- 新郎等待新娘入场
- **新娘入场（极其重要！）**
- 父亲把新娘交给新郎的瞬间
- 交换誓词
- **交换戒指（极其重要！）**
- **亲吻（极其重要！）**
- 签署结婚证书
- 新人退场
- 宾客祝福/鼓掌

**特别建议：** 
- 安排一个机位专门拍新人的**表情特写**
- 安排一个机位拍**全景和宾客反应**
- 如果有致辞环节，确保**音频录制清晰**

### 4. 婚纱照/合影环节

**建议素材量：50-100张照片**

- 新人合影（多角度、多场景）
- 新人与双方父母合影
- 新人与伴郎伴娘合影
- 新人与亲友合影
- 创意合影（比如抛花球）

### 5. 婚礼宴会

**建议素材量：30-50张照片 + 10-15段视频**

- 宴会场地全景
- 新人入场
- 第一支舞
- 切蛋糕
- 敬酒环节
- 游戏/互动环节
- 抛花球
- 宾客祝酒
- 感人瞬间（父母致辞、朋友祝福等）

如果你们在婚礼前已经拍了婚纱照，这些照片也是婚礼视频的绝佳素材。

## 六、素材数量建议总结

### 最低要求（制作一个简单的婚礼视频）

- 照片：50-100张
- 视频片段：10-20段
- 音频：1-2首背景音乐

### 推荐数量（制作一个高质量的婚礼视频）

- 照片：150-300张
- 视频片段：30-50段
- 音频：3-5首背景音乐 + 现场录音

### 理想数量（制作一个完美的婚礼视频）

- 照片：300-500张
- 视频片段：50-100段
- 音频：5-10首背景音乐 + 完整现场录音 + 亲友祝福

## 七、素材拍摄技巧

### 照片拍摄技巧

1. **多角度**：同一个场景，从不同角度多拍几张
2. **注意光线**：尽量在光线充足的环境下拍摄
3. **稳定画面**：双手持稳手机，或者使用三脚架
4. **注意构图**：不要把人物放在画面正中间，留出适当的背景
5. **抓拍表情**：最自然的表情往往比摆拍更动人

### 视频拍摄技巧

1. **保持稳定**：使用稳定器或三脚架，避免画面抖动
2. **横屏拍摄**：婚礼视频通常使用横屏格式
3. **注意声音**：确保麦克风能清晰录到重要的声音（如誓词）
4. **多拍几段**：每个场景多拍几段，后期可以选择最好的
5. **注意时长**：每段视频不要太长，15-60秒为宜

## 八、素材整理和管理

### 文件命名规范

建议使用统一的命名规范，方便后期查找：

```

2026-07-30_接亲_01.mp4

```

```
📁 2026-07-30_婚礼/
├── 📁 01_恋爱时期/
├── 📁 02_备婚过程/
├── 📁 03_婚礼当天/
│   ├── 📁 新娘准备/
│   ├── 📁 新郎准备/
│   ├── 📁 接亲/
│   ├── 📁 仪式/
│   ├── 📁 合影/
│   └── 📁 宴会/
├── 📁 04_婚纱照/
├── 📁 05_特殊素材/
│   ├── 📁 家人祝福/
│   ├── 📁 朋友祝福/
│   └── 📁 宠物/
└── 📁 06_音频/
    ├── 📁 背景音乐/
    └── 📁 现场录音/
```

### 备份策略

**3-2-1备份原则：**
- **3份副本**：原始文件 + 本地备份 + 云端备份
- **2种介质**：硬盘 + 云存储
- **1份异地**：至少一份备份存放在不同的物理位置

**推荐的云存储：** 百度网盘、Google Photos、iCloud
